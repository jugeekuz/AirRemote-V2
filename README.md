Turn your old remote-controlled devices into smart devices! AirRemote captures the infrared (IR) signals of any remote control and lets you replay them remotely, from a web interface or on a schedule.

## 🚧 Status

AirRemote V2 is being rewritten from scratch: the backend first, then the firmware, then the frontend. The new code lives in `backend/`, `firmware/` and `frontend/` as each part is built.

The original V1 code is at the tag [`v1-final`](https://github.com/jugeekuz/AirRemote-V2/tree/v1-final).

| Folder at `v1-final` | What it is | Previously |
| --- | --- | --- |
| [`frontend/`](https://github.com/jugeekuz/AirRemote-V2/tree/v1-final/frontend) | The V1 web interface | [AirRemote-Frontend](https://github.com/jugeekuz/AirRemote-Frontend) |
| [`backend/`](https://github.com/jugeekuz/AirRemote-V2/tree/v1-final/backend) | The V1 serverless API | [AirRemote-Backend](https://github.com/jugeekuz/AirRemote-Backend) |
| [`firmware/`](https://github.com/jugeekuz/AirRemote-V2/tree/v1-final/firmware) | The V1 ESP32 PlatformIO firmware | [AirRemote-Embedded](https://github.com/jugeekuz/AirRemote-Embedded) |

The full commit history of all three repositories is preserved here.
