Turn your old remote-controlled devices into smart devices! AirRemote captures the infrared (IR) signals of any remote control and lets you replay them remotely, from a web interface or on a schedule.

## 🌟 Repository layout

| Folder | What it is | Previously |
| --- | --- | --- |
| [`frontend/`](frontend) | The web interface | [AirRemote-Frontend](https://github.com/jugeekuz/AirRemote-Frontend) |
| [`backend/`](backend) | The serverless API | [AirRemote-Backend](https://github.com/jugeekuz/AirRemote-Backend) |
| [`firmware/`](firmware) | The ESP32 PlatformIO firmware | [AirRemote-Embedded](https://github.com/jugeekuz/AirRemote-Embedded) |

Each folder keeps its own README with setup and deployment instructions. The full commit history of all three repositories is preserved here.
